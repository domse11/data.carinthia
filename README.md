# 📅 Event API Display – WordPress Plugin

Dieses Projekt ist ein WordPress-Plugin zur Anzeige von Veranstaltungsdaten aus der [data.carinthia.com API](https://data.carinthia.com/).  
Es ruft Events automatisch ab und zeigt sie übersichtlich auf einer WordPress-Seite an – inklusive Bildern, Beschreibung und einem "Mehr anzeigen"-Button für längere Texte.

---

## 🔧 Funktionen

- 📡 Holt Event-Daten per API aus Kärnten (data.carinthia.com)
- 🖼️ Zeigt Eventnamen, Datum, Beschreibung und Bilder
- 🧾 Formatierte Texte mit automatischem Umbruch
- 🔽 Dynamische Umschaltung zwischen Kurz- und Langbeschreibung
- ⚙️ Einbindung per Shortcode `[event_api]` auf beliebiger Seite

---

## 🛠️ Technologien

- PHP
- JavaScript (DOM-Manipulation)
- WordPress Plugin-System
- REST API (JSON)
- Regex-Parsing & HTML-Ausgabe
